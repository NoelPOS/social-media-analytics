**10:15 - 10:25: Introduction to Analysis** (10 min)

**Present the Analysis Framework:**

```
ANALYSIS = Turning Raw Data into Insights

Raw Numbers → Patterns → Insights → Actions
```

**The Four Key Questions:**
1. "What happened?" (Descriptive)
2. "Why did it happen?" (Diagnostic)
3. "What will happen?" (Predictive)
4. "What should we do?" (Prescriptive)

**Example:**
```
What: Engagement dropped 30% last week
Why: Posted at different times than usual
What will: If we continue, engagement stays low
Do: Return to optimal posting times
```

**10:25 - 10:40: Trend Analysis** (15 min)

**Definition:** Tracking metrics over time to identify patterns

**Show Example Data on Screen:**


**Types of Trends:**

**1. Linear Trend**
```
Steady increase or decrease

```

**2. Exponential Trend**
```
Accelerating growth
Example: Viral content, each share creates more shares
```

**3. Seasonal Trend**
```
Cyclical patterns
Example: Retail high during holidays, low in January
```

**4. Declining Trend**
```
Decreasing over time
Example: Engagement dropping as algorithm changes
```

**Hands-On: Identify the Trend** (5 min)

1. Steady upward line → Linear growth

#### 11:15 - 12:00 PM: Engagement & Sentiment Analysis (45 min)

**Objectives:**
- Understand engagement quality
- Learn sentiment analysis basics

**11:15 - 11:30: Deep Dive into Engagement** (15 min)

**Beyond the Numbers:**

**Engagement Hierarchy:**
```
HIGHEST VALUE
↓
Share/Retweet (Amplification)
Save (Intent)
Comment (Conversation)
Like/Reaction (Acknowledgment)
View (Passive)
↓
LOWEST VALUE
```

**Why It Matters:**

**Example 1:**
```
Post A: 1,000 likes, 10 comments
Post B: 500 likes, 200 comments

Which is better?
Answer: Depends on goal!
- Brand awareness → Post A (more people)
- Community building → Post B (more conversation)
```

**Engagement Quality Indicators:**

**1. Comment Depth**
- "Great!" → Low quality
- "I tried this and here's what happened..." → High quality

**2. Response Rate**
- Do you reply to comments? You should!
- Brands replying = 2x more engagement

**3. Share Context**
- Share with comment → High value
- Silent share → Lower value

**4. Save Intent**
- Instagram saves = "I want to return to this"
- Recipes, tutorials, inspiration get saved

**Calculate Weighted Engagement:**
```
Standard: Likes + Comments + Shares
Weighted: (Likes × 1) + (Comments × 3) + (Shares × 5)

Example:
100 likes + 20 comments + 5 shares

Standard: 125 engagements
Weighted: (100×1) + (20×3) + (5×5) = 185 value
```

**11:30 - 11:50: Introduction to Sentiment Analysis** (20 min)

**What is Sentiment Analysis?**

```
Analyzing the EMOTION behind social media interactions

Categories:
😊 Positive
😐 Neutral
😢 Negative
```

**Why It Matters:**

1. **Brand Health Monitoring**
   - Are people happy with your brand?
   - Early warning for issues

2. **Campaign Effectiveness**
   - Is your message resonating?
   - Are people excited or angry?

3. **Customer Service**
   - Identify frustrated customers
   - Prioritize urgent responses

4. **Product Feedback**
   - What do customers love/hate?
   - Feature requests and complaints

**Manual Sentiment Scoring:**

**Example Comments:**

**Positive Examples:**
- "This is amazing! Just ordered mine!" → ✅ Positive
- "Best product ever. Highly recommend." → ✅ Positive
- "Thank you for such great customer service!" → ✅ Positive

**Neutral Examples:**
- "When will this be available in blue?" → ↔️ Neutral (question)
- "I'm considering buying this" → ↔️ Neutral (undecided)
- "Received my order today" → ↔️ Neutral (statement)

**Negative Examples:**
- "Worst purchase ever. Save your money." → ❌ Negative
- "Still waiting for response to my issue..." → ❌ Negative
- "Disappointed with quality" → ❌ Negative

**Mixed Sentiment:**
- "Love the design but hate the price" → Both positive and negative
- Usually code as the dominant sentiment

**Intensity Matters:**
- "Good" → Positive
- "AMAZING!!!" → Strongly Positive
- "It's okay" → Weakly Positive/Neutral

**Sarcasm is Hard:**
- "Oh great, another delay 🙄" → Negative (despite "great")
- Context clues: emoji, punctuation, tone

**11:50 - 12:00: Hands-On Sentiment Analysis** (10 min)

**Activity: Score These Comments**

Distribute sentiment analysis worksheet (or display on screen).

**10 Comments to Score:**

1. "Just got mine and I'm obsessed! 😍"
2. "Still haven't received my order from 2 weeks ago"
3. "How much does shipping cost?"
4. "Your customer service team was so helpful!"
5. "This broke after one use. Waste of money."
6. "Looks interesting, might try it"
7. "Best purchase I've made all year!"
8. "Why did you change the formula? Old one was better"
9. "What colors does this come in?"
10. "Not worth the price IMO"

**Students work individually:** (3 min)
Mark each as Positive, Neutral, or Negative

**Review Together:** (5 min)
- Call on students for answers
- Discuss any disagreements
- Explain reasoning

**Answer Key:**
1. Positive (clear enthusiasm)
2. Negative (complaint about service)
3. Neutral (information seeking)
4. Positive (praise)
5. Negative (product failure + regret)
6. Neutral (interest but no commitment)
7. Positive (strong endorsement)
8. Negative (complaint about change)
9. Neutral (question)
10. Negative (criticism of value)

**Calculate Sentiment Score:**
```
Sentiment Score = (Positive - Negative) / Total × 100

Example from our 10 comments:
Positive: 3
Neutral: 3
Negative: 4

Score = (3 - 4) / 10 × 100 = -10 (slightly negative)
```

**Interpretation:**
- +50 to +100: Very positive
- +10 to +50: Positive
- -10 to +10: Neutral/Mixed
- -50 to -10: Negative
- -100 to -50: Very negative

**Real-World Application:**
"Major brands track sentiment daily. A sudden drop signals crisis. A spike in positive sentiment confirms campaign success."

**Materials:**
- Engagement quality examples
- Sentiment analysis comment samples
- Scoring worksheets
- Answer keys

**Teaching Tips:**
- Use real comments (anonymized)
- Discuss edge cases and disagreements
- Emphasize that sentiment analysis is somewhat subjective
- Show how brands use this data
- Mention automated tools (but manual is good for learning)

**1:30 - 1:40: Why Visualization Matters** (10 min)

```
The human brain processes images 60,000x faster than text
```

**Show Example:**

**Text Version:**
"Engagement rate increased from 3.2% in January to 4.5% in February to 6.1% in March to 7.8% in April."

**Visual Version:**
[Show line chart with clear upward trend]

**Ask:** "Which is easier to understand instantly?"
- Obviously the chart!

**Why Visualize?**

1. **Pattern Recognition**
   - Spot trends instantly
   - See outliers clearly

2. **Communication**
   - Present to stakeholders
   - Report to clients
   - Pitch to executives

3. **Decision Making**
   - Compare options visually
   - See cause-and-effect

4. **Engagement**
   - Visuals in reports get more attention
   - Infographics get shared

**1:40 - 2:00: Chart Types & Selection** (20 min)

**The Right Chart for the Job:**

**1. Line Chart**
- **Use for:** Trends over time
- **Example:** Follower growth, engagement over months
- **When to use:** Continuous data, time series
```
Perfect for: "How has this metric changed?"
```

**2. Bar Chart (Vertical/Horizontal)**
- **Use for:** Comparing categories
- **Example:** Engagement by content type, platform comparison
- **When to use:** Discrete categories
```
Perfect for: "Which one is highest/lowest?"
```

**3. Pie Chart**
- **Use for:** Parts of a whole (use sparingly!)
- **Example:** Audience demographics, traffic sources
- **When to use:** Limited categories (3-5 max), percentages add to 100%
- **⚠️ Caution:** Hard to compare similar sizes
```
Perfect for: "What's the breakdown?"
Better alternative: Often a bar chart
```

**4. Scatter Plot**
- **Use for:** Correlation between two variables
- **Example:** Posting frequency vs. engagement, followers vs. reach
- **When to use:** Looking for relationships
```
Perfect for: "Is there a relationship between X and Y?"
```

**5. Heatmap**
- **Use for:** Patterns across two dimensions
- **Example:** Best posting time (day × hour), engagement by day/time
- **When to use:** Time-based patterns
```
Perfect for: "When is the best time?"
```

**6. Area Chart**
- **Use for:** Volume over time, stacked categories
- **Example:** Traffic sources over time
- **When to use:** Showing cumulative total
```
Perfect for: "How do parts contribute to the whole over time?"
```

**Quick Reference:**
```
Question Type          → Chart Type
----------------       → ----------
Trend over time       → Line chart
Compare categories    → Bar chart
Show proportion       → Pie chart (or bar)
Find correlation      → Scatter plot
Time patterns         → Heatmap
Volume over time      → Area chart
```

**2:00 - 2:20: Design Principles** (20 min)

**The Good, The Bad, The Ugly:**

**Show examples of GOOD visualizations:**
1. Clear title
2. Labeled axes
3. Simple color scheme
4. Appropriate scale
5. Clean layout
6. Source noted

**Show examples of BAD visualizations:**
1. No title or unclear
2. Missing labels
3. Too many colors
4. Misleading scale
5. 3D effects (distortion)
6. Chartjunk (unnecessary decoration)

**Design Principles:**

**1. Clarity Above All**
```
Can someone understand this in 5 seconds?
If not, simplify.
```

**2. Data-Ink Ratio** (Edward Tufte)
```
Maximize the data-ink ratio
Remove anything that doesn't convey information
- No 3D effects
- No unnecessary gridlines
- No decorative elements
```

**3. Color Usage**
```
✅ Use color with purpose
   - Highlight important data
   - Group related items
   - Show positive/negative

❌ Don't:
   - Use rainbow colors randomly
   - Rely on color alone (accessibility!)
   - Use red/green only (colorblind)
```

**Color Best Practices:**
- 2-3 colors maximum for most charts
- Consistent color scheme across dashboard
- Brand colors when appropriate
- Consider colorblind-friendly palettes

**4. Scale and Axes**
```
✅ Start Y-axis at zero (for bar charts)
✅ Use appropriate intervals
✅ Label all axes clearly

❌ Don't:
   - Manipulate scale to exaggerate
   - Use broken axes without clear indication
   - Leave axes unlabeled
```

**5. Context and Annotations**
```
✅ Add benchmarks (industry average)
✅ Highlight important points
✅ Add brief explanatory text
✅ Note data source and date

Example: "Engagement spiked 200% after influencer mention"
```

**Show Before/After Examples:**

**BEFORE (Bad):**
- 3D pie chart
- 10 different colors
- No labels
- Cluttered

**AFTER (Good):**
- Simple bar chart
- 2-3 colors
- Clear labels
- Clean

**2:20 - 2:30: Common Mistakes** (10 min)

**Top 10 Visualization Mistakes:**

**1. Wrong Chart Type**
```
❌ Pie chart with 15 slices
✅ Bar chart instead
```

**2. Misleading Scale**
```
❌ Y-axis starting at 95 (makes 96-100 look huge)
✅ Start at 0 or clearly mark break
```

**3. Too Much Information**
```
❌ 10 metrics on one chart
✅ Focus on 2-3 key metrics
```

**4. No Title or Labels**
```
❌ Chart with no explanation
✅ "Engagement Rate by Platform (Jan 2026)"
```

**5. 3D Charts**
```
❌ 3D pie chart (distorts perception)
✅ 2D flat chart
```

**6. Dual Y-Axes** (advanced mistake)
```
⚠️ Use carefully - can mislead
✅ Better: Two separate charts
```

**7. Inconsistent Time Scales**
```
❌ Comparing daily data to monthly
✅ Normalize to same period
```

**8. Rainbow Colors**
```
❌ Every bar a different color (no meaning)
✅ Color to highlight or group
```

**9. Tiny Text**
```
❌ Labels too small to read
✅ Readable font size (minimum 10pt)
```

**10. No Context**
```
❌ "Engagement: 5.2%" (Is that good?)
✅ "Engagement: 5.2% (+1.5% vs last month, above 3.8% industry average)"
```

**Quick Quiz:** Show 3 charts, students identify the mistake.

- Before/after examples

- Show lots of visual examples

**2:45 - 3:00: Dashboard Design Principles** (15 min)

**What is a Dashboard?**

```
A visual display of key metrics and KPIs, 
designed for at-a-glance monitoring and decision-making
```

**Dashboard vs. Report:**
- **Dashboard:** Real-time, interactive, high-level
- **Report:** Detailed, static, comprehensive

**Good Dashboard Characteristics:**

**1. Clear Hierarchy**
```
Most important metrics → Top/largest
Secondary metrics → Supporting positions
```

**Visual Hierarchy Example:**
```
┌─────────────────────────────────┐
│  MAIN METRIC: Engagement Rate   │  ← Largest, top
│         6.8% ↑ 1.2%             │
├────────────┬────────────┬───────┤
│  Followers │   Reach    │ Posts │  ← Secondary metrics
│   25,000   │   58,000   │  45   │
├────────────┴────────────┴───────┤
│     [Chart: Trends]             │  ← Supporting visual
└─────────────────────────────────┘
```

**2. Logical Grouping**
```
Group related metrics together
- Audience metrics in one section
- Content performance in another
- Engagement in third section
```

**3. Consistent Layout**
```
Same style throughout
- Same fonts
- Same colors
- Same chart types (when appropriate)
- Aligned elements
```

**4. White Space**
```
Don't cram everything together
Give metrics room to breathe
Easier to scan and understand
```

**5. Interactive Elements** (when possible)
```
- Filters (by date, platform, content type)
- Dropdowns
- Slicers
- Hover information
```

**Dashboard Layout Patterns:**

**Pattern 1: F-Pattern**
```
Users scan in F-shape (top, left to right, down left side)
Put most important info top-left
```

**Pattern 2: Z-Pattern**
```
For simpler dashboards
Key metric top-left, action top-right
Supporting info bottom
```

**Pattern 3: Grid**
```
Equal-sized metric cards
Clean, organized
Good for multiple KPIs
```
