### Exercise 1.1: Identify the Trend ⭐

**Given monthly follower data, identify the trend type.**

**Data Set A:**
```
Month 1: 1,000 followers
Month 2: 1,500 followers
Month 3: 2,250 followers
Month 4: 3,375 followers
Month 5: 5,063 followers
```

**Questions:**
1. What type of trend is this?

### Exercise 3.3: Weighted Sentiment Analysis ⭐⭐

**Not all commenters are equal. Influencer comments reach more people.**

**Scenario:** Product review comments

| Commenter | Followers | Sentiment | Comment |
|-----------|-----------|-----------|---------|
| User A | 500 | Positive | "Love it!" |
| Influencer B | 100,000 | Negative | "Disappointed with quality" |
| User C | 1,200 | Positive | "Great product!" |
| User D | 300 | Neutral | "How long does shipping take?" |
| Influencer E | 50,000 | Positive | "Best I've tried!" |
| User F | 800 | Negative | "Not worth the money" |

**Standard Sentiment:**
- Count: P=3, N=1, NEG=2
- Score: +16.7

**Weighted by Follower Count:**
1. Multiply each sentiment by follower count
2. Calculate weighted score
3. How different is it from standard?
4. What does this tell you about reputation management?
