### Exercise 17: ROI Calculation

**Objective:** Calculate return on investment from social media

**Scenario:**
You spent $2,000 on a Facebook ad campaign.

**Results:**
- 50,000 impressions
- 1,500 clicks (CTR = 3%)
- 450 website visits
- 45 purchases
- Average order value: $80
- Total revenue: $3,600

**Calculate:**

1. Cost Per Click (CPC) = Total Spend / Clicks
   ```
   CPC = $2,000 / 1,500 = $_______
   ```

2. Cost Per Acquisition (CPA) = Total Spend / Purchases
   ```
   CPA = $2,000 / 45 = $_______
   ```

3. Return on Ad Spend (ROAS) = Revenue / Spend
   ```
   ROAS = $3,600 / $2,000 = _______ (or _______%)
   ```

4. ROI = (Revenue - Spend) / Spend × 100
   ```
   ROI = ($3,600 - $2,000) / $2,000 × 100 = _______%
   ```

**Questions:**

1. Was this campaign profitable? _________________________________________________

2. What's the breakeven ROAS? ____________________________________________________

3. What would you optimize to improve ROI? ______________________________________
