## ✅ Activities Overview

### 1. Competitive Audit Workshop (20 min)
**Objective:** Analyze 5 competitors and create a competitive matrix  
**Format:** Individual work, then pair-share  
**Deliverable:** Completed competitive audit template

### 2. Campaign Tracking Setup (15 min)
**Objective:** Create UTM parameters for a campaign  
**Format:** Individual practice  
**Deliverable:** 5 properly formatted UTM links

### 3. ROI Calculation Exercise (20 min)
**Objective:** Calculate ROI for 4 different scenarios  
**Format:** Individual work with Excel  
**Deliverable:** Completed ROI calculations with recommendations

### 4. Report Makeover Challenge (25 min)
**Objective:** Transform a poorly designed report into an executive-ready version  
**Format:** Pairs  
**Deliverable:** Redesigned one-page report

### 5. 2-Minute Presentation Practice (20 min)
**Objective:** Practice delivering key insights concisely  
**Format:** Pairs, then volunteer presentations  
**Deliverable:** 2-minute pitch with 3 key insights

### 6. Case Study Analysis (20 min)
**Objective:** Learn from real-world successes and failures  
**Format:** Small groups (3-4 people)  
**Deliverable:** Group discussion and key lessons identified

### 7. Final Project Work Time (50 min)
**Objective:** Apply all concepts to comprehensive analysis  
**Format:** Individual work with instructor support  
**Deliverable:** Progress on final project (due after course)

## 📝 Notes for Instructors

**Pacing:**
- Day 3 moves faster—students have foundation from Days 1-2
- Build in reflection time during breaks
- Use case studies to illustrate concepts
- Final project work time is sacred—minimize interruptions

**Common Challenges:**
- ROI calculations can be confusing—use clear examples
- Students may struggle with executive communication style
- Time management during final project work
- Balancing technical depth with practical application

**Engagement Tips:**
- Use real brand examples students know
- Invite volunteers to present to the class
- Share your own reporting experiences
- Make final project work time collaborative

**Flexibility:**
- If running behind, shorten case study discussion
- Can extend final project work time if needed
- Adjust report makeover activity based on skill level
